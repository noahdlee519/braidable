Connect to GitHub

Publishing saves your changes to the site's GitHub repository, and the live site updates about a minute later. This page needs a GitHub token that can edit that one repository.

  1. Open GitHub's new token page (fine-grained token).
  2. Name it something like braidable editor and pick an expiration.
  3. Under Repository access, choose Only select repositories and pick braidable.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate the token, copy it, and paste it below.

The token stays in this browser and is only ever sent to GitHub.
